# Roadmap

## v0.1 — Windows community prototype

- [x] Interactive PowerShell configuration
- [x] Current-user DPAPI storage
- [x] Hidden Windows login autostart
- [x] Runner status, stop and local-config removal helpers
- [ ] Independent Windows 10/11 end-to-end tests
- [ ] External security review and code signing

## v0.2 — Setup experience

- [ ] Graphical installer with explicit access-permission review
- [ ] Automatic distinction between MCP direct listener and Codex broker URL
- [ ] Verified installation of official tunnel-client release, with checksum verification
- [ ] Robust logging, duplicate-process diagnostics and credential rotation controls

## v0.3 — Broader support

- [ ] macOS and Linux credential-store integrations
- [ ] Clear multi-client profiles and endpoint policies
- [ ] Tested failure recovery and permissions

## v0.4 — Real Obsidian plugin (separate build)

- [ ] Obsidian UI with `manifest.json` and compiled `main.js`
- [ ] Settings workflow and existing MCP Connector interoperability
- [ ] Community Plugins submission after review and tested releases

## Research backlog

Multi-vault federation, portable AI memory, provenance-aware knowledge graphs and approval-controlled agent writes are future research, **not features of v0.1**.
