# Publication notes

Only publish the **source repository**. Do not upload local installation directories containing encrypted credentials, Tunnel IDs, user paths or Vault files.

- Label the release **v0.1.0 community prototype**, not a production-grade installer.
- Verify Git history for accidental credentials before announcing the repo.
- Test on an independent Windows machine before publishing a signed installer.
- Attach only sanitized screenshots and logs.
- Do not submit this release to Obsidian Community Plugins: it is a Windows helper, **not** a plugin with `manifest.json` and compiled `main.js`.

Official plugin submission guidance: https://docs.obsidian.md/Plugins/Releasing/Submit%20your%20plugin
