# Changelog

## 0.1.0 — Public starter package

- Initial Windows-only local tunnel setup and launcher.
- DPAPI storage, hidden Startup shortcut, local MCP authentication check and OpenAI runtime key preflight.
- Status, safe stop, startup removal and bilingual documentation.
- No private data, no preconfigured Tunnel IDs or tokens.

Known limitations: not an Obsidian plugin; no independent Windows end-to-end validation yet.
